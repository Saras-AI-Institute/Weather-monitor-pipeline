# Weather Monitor Pipeline

An automated data pipeline built in Databricks to ingest, process, and analyze weather forecast data.

## Overview
This repository contains the `Weather Forecast-Databricks.ipynb` notebook, which handles fetching weather data, transforming it, and generating forecasts.

## Prerequisites
- Databricks Workspace (Community Edition or Standard/Premium)
- Python 3.x
- API Key for the weather data provider

## Setup & Usage
1. Clone this repository or import `Weather Forecast-Databricks.ipynb` into your Databricks workspace.
2. Attach the notebook to an active Databricks cluster.
3. Configure your API credentials in the notebook parameters or Databricks Secrets.
4. Run all cells to execute the pipeline.
